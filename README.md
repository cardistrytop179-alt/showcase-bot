# Showcase Portfolio Bot

Демонстрационный Telegram-бот-портфолио на Node.js, grammY, Prisma и PostgreSQL.

## Что умеет

- Показывает карточку разработчика и список проектов.
- Проводит пользователя через пошаговую форму и сохраняет состояние в базе.
- Показывает курсы криптовалют через CoinGecko.
- Возвращает пользователей, не закончивших форму, с ограниченным числом напоминаний.
- Предоставляет административную статистику и рассылку.

## Запуск

1. Установите Node.js 18+ и PostgreSQL.
2. Установите зависимости: `npm install`.
3. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`, `DATABASE_URL` и `ADMIN_ID`.
4. Выполните `npm run db:generate`, затем `npm run db:push`.
5. Запустите `npm start`.

Токены и реальные данные пользователей не входят в репозиторий. Это учебный пример: перед использованием в реальном проекте настройте политику хранения и удаления пользовательских данных.
